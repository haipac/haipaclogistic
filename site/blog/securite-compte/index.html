ESPACE CLIENT · SÉCURITÉ

Protéger son
espace client.

Quelques habitudes utiles pour garder le contrôle de votre accès personnel.

Lecture : 2 minMis à jour : novembre 2026
Dans ce guideRecevoir le lienUtiliser le lienDemander de l’aide

L’espace client utilise un lien de connexion envoyé à l’adresse e-mail que vous avez saisie. Ce lien est personnel et doit rester sous votre contrôle.

01

Utiliser votre adresse e-mail.

Ouvrez la page Mon espace et demandez un lien avec l’adresse e-mail que vous souhaitez associer au compte. Consultez ensuite cette boîte de réception pour poursuivre la connexion.

Si vous n’avez pas demandé de lien, ne cliquez pas sur un message inattendu. Vous pouvez simplement l’ignorer.

02

Garder le lien privé.

Le lien est utilisable une seule fois et expire après quatorze jours. Ne le transférez pas et évitez de le copier dans un message ou un document partagé. Si un lien a déjà été utilisé ou a expiré, demandez-en un nouveau depuis la page de connexion.

Un colis n’apparaît pas dans le compte ?

Le rattachement doit être fait avec l’adresse e-mail destinataire et les vérifications demandées par HAIPAC.

03

Demander de l’aide sans partager de secret.

Pour une question générale, utilisez le formulaire de contact. N’envoyez jamais votre mot de passe, un code de connexion ou des données de carte bancaire par e-mail.
